# Runtime UI Icons

Drop optional PNG icons for Bevy runtime UI in this folder. The game loads only files that exist, so missing icons fall back to text-only UI.

Expected file names:

- `save.png`
- `close.png`
- `settings.png`
- `map.png`
- `inventory.png`
- `chat.png`
- `pickaxe.png`
- `torch.png`
- `axe.png`
- `terrain_raise.png`
- `terrain_lower.png`
- `terrain_level.png`
- `terrain_smooth.png`
- `warning.png`

These are normal Bevy image assets. Do not generate icons at runtime.
